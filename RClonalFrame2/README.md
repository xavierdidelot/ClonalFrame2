# Introduction

The aim of this package is to provide a R interface for ClonalFrame2.

## Installation

You can install RClonalFrame2 from github with:

``` r
devtools::install_github("xavierdidelot/RClonalFrame2")
```

The package can then be loaded using:

``` r
library(RClonalFrame2,quietly=T)
```
